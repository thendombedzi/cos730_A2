# COS730 Assignment 2: Code Implementations

This repository holds the Java code for COS730 Assignment 2, where we explored how to improve a submission and review system. You'll find two versions:

1.  **Baseline**: The original system, built as per the initial design.
2.  **Optimised**: A refined version that fixes the original system's shortcomings, using a decision table and better architectural patterns.

## What's Inside

-   `BaselineImplementation.java`: The code for the initial system.
-   `OptimisedImplementation.java`: The code for the improved system.
-   `README.md`: This very file.
-   `.gitignore`


## How to Run

1.  **Compile**: Open your terminal, navigate to this project's directory, and run:

    ```bash
    javac *.java
    ```

    This will create the necessary `.class` files.

2.  **Run the Baseline**: To see the original system in action:

    ```bash
    java BaselineImplementation
    ```

    You'll see how the submission and review process unfolds with the initial, less efficient design.

3.  **Run the Optimised Version**: To check out the improved system:

    ```bash
    java OptimisedImplementation
    ```

    This will show you a smoother, more efficient submission and review flow, thanks to the architectural improvements.
